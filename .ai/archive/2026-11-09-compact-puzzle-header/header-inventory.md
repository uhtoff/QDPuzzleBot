## Where a per-puzzle layout flag would need to be consulted

Read-side (decides geometry; must take the puzzle, not a global):
1. `_header_shift` G:200 -- already the central col-offset oracle for solve/unsolve/update_solution/rename/`_solution_bg_request`/`refresh_header_links`. Extend (or add `_header_layout(puzzle, page_id)` returning cell map: name/solution/progress/feeds refs, shift, frozen rows, last col, table header row).
2. `generate_puzzle_tab` G:1945 -- bypasses `_header_shift` (`offset = TARGET_HEADER_SHIFT if is_target else 0`, G:1970) and passes `header_row=FROZEN_ROWS` (G:1990). Must pick layout for a NEW puzzle here and persist it on the puzzle.
3. `_puzzle_tab_header_requests` G:1775 -- the single place all labels, merges, name cell, formatting and Feeds are emitted (create, files-create retry, promote, demote). Needs layout arg; it reads `sheet_layout.PUZZLE_TAB_CELLS/MERGES` via `puzzle_tab_layout(is_target)` SL:61 (add layout param there).
4. Formatting trio: `_tab_format_requests` G:224, `_header_border_request` G:292, `_label_bold_requests`/`_dynamic_bold_requests` G:250/269 (use FROZEN_ROWS, HEADER_LAST_COL, `config.puzzle_cell_solution`).
5. Feeds: `header_links_request` G:1822 and `_feeds_line_requests` G:1855 (FEEDS_LINKS_A1/LABEL_A1, row-3 merges); caller `refresh_header_links` PS:3744 (passes offset; would need to pass layout or let the cog derive it).
6. Cell-address writers that use `config.puzzle_cell_*` directly: `update_puzzle_info` G:318, `update_solution` G:696, `move_puzzle_to_solved_sheet` G:710 (incl. extras G:738-742), `restore_puzzle_from_solved_sheet` G:630 (incl. extras G:668-673), `_solution_bg_request` G:305.
7. Table anchor: `_add_contribution_table` callers all use `sheet_layout.FROZEN_ROWS` (G:1990, 2076, 2126, 2176, 2185); `_ensure_contribution_table` G:2127; `reconcile_table` is Table-range driven (safe).
8. In-place re-lay paths that read AND write the header: `promote_tab_to_target` G:2041, `demote_tab_to_puzzle` G:1139, and the probe `_tab_layout` G:2007 (LAYOUT_PLAIN/TARGET/UNKNOWN keyed on "Puzzle Title:" at A1/B1; with a new header it would misclassify new tabs as UNKNOWN, and `_ensure_contribution_table` G:2181 / demote guard would skip). Promote/demote of an OLD-layout tab must keep old geometry; of a NEW tab must use new; layout must be read from the persisted flag (or from the tab), never from "now".
9. Persistence/plumbing: PuzzleData field (store near `google_page_id`, bot/store/mysqldb.py) set in `generate_puzzle_tab`; `PuzzleService._header_links_kw` PS:3691 and callers PS:1432, 1957, 2564, 3018, 3285 (they pass header_links only, layout flows via puzzle object).
10. Not needing a flag: `move_puzzle_sheet` G:561, `_move_puzzle_file`, `compute_insert_index`, `select_table`/`contribution_table_name`, unassigned/evidence tabs.
